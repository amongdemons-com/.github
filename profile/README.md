## The Game

Among Demons is a dark browser roguelike built around permanent demon collection and server-simulated combat.

* Descend through endless dungeon floors
* Recruit defeated demons
* Shape each run with Demonic Pacts
* Explore a dangerous 101×101 world
* Hunt world encounters and bosses
* Challenge other hunters in PvP
* Train your collection and climb the rankings
* Extract safely or lose everything earned during the run
